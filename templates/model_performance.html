Understanding the Mathematical Metrics

MAE • Mean Absolute Error

Definition: The average of the absolute differences between the predictions and actual values.

Interpretation: MAE is measured in the same unit as the target variable (marks). Lower values generally indicate smaller prediction errors. An MAE of ~{{ metrics.mae }} means predictions typically diverge by about {{ metrics.mae }} marks from true scores.

R² • Coefficient of Determination

Definition: Represents the proportion of variance for a dependent variable that's explained by an independent variable.

Interpretation: Indicates how well the model explains variation in the target data. An R² of 1.0 represents a perfect fit, while 0.0 indicates the model predicts no better than the sample mean. Here, R² = {{ metrics.r2_score }}, indicating strong predictive capability for study time.
