Machine Learning Architecture

How It Works: End-to-End ML Pipeline

A transparent, 9-stage engineering workflow from raw student data to real-time inference

01

Load CSV Dataset

Load the student records CSV into memory using Pandas DataFrame data structures.

02

Inspect & Clean

Check missing values, handle null entries, and filter invalid boundaries.

03

Explore Data

Explore distributions, calculate statistical summaries, and plot relationships with Matplotlib.

04

Separate Features & Target

Isolate independent feature vector X (Study Hours) and dependent target y (Marks).

05

Split Data

Partition records using train_test_split (80% train, 20% test) with a fixed seed.

06

Train Linear Regression

Fit Ordinary Least Squares Linear Regression using Scikit-Learn to find slope m and intercept c.

07

Evaluate Performance

Compute test metrics including Mean Absolute Error (MAE) and Coefficient of Determination (R²).

08

Serialize Model

Save the trained estimator to model.pkl and metrics to JSON using Joblib.

09

Flask Inference Engine

Load model.pkl on web startup and process validated prediction queries asynchronously.
